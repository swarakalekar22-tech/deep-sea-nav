An AI-powered **surface navigation** demo built with Python (Flask) and a modern single-page website UI. The system simulates GPS-based routing, surface-level obstacle detection, and an AI navigation engine that computes headings and routes in real time.
**Surface GPS Navigation** – Simulated coordinates and waypoints to represent vessel position and targets.
- **Surface Obstacle Detection** – Distance-based warning levels: `safe`, `caution`, and `danger`.
- **AI Navigation Logic** – A* pathfinding on a grid, heading calculation between GPS points, and simple route optimization.
- **Interactive Web UI** – Dark, ocean-themed website with sections for About, Architecture, Features, Applications, Tech Stack, AI System, and a Live Demo.
- **Live Simulator** – Canvas-based vessel simulator that animates a surface route on a 20x20 grid.
**Frontend:** HTML, CSS, JavaScript, Chart.js
- **Backend:** Python, Flask
- **AI / Data:** NumPy, (demonstration-friendly structure for Pandas / scikit-learn)
